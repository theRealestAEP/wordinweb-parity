ChatGPT and Codex plugin · Publication in preparation

Your Word document, open beside your chat.

Read, review, and edit .docx files with WordInWeb. Ask for a wording change, adjust the formatting, or highlight a passage and add it to chat.

Edit the words. Keep the style.

Simple wording edits keep existing paragraph styles and text formatting. Ask chat to shorten a sentence, rewrite a paragraph, or summarize the document.

Work with the whole page.

Change alignment and styles, edit tables, adjust page layout, and review comments in the document editor.

Point to the passage you mean.

Select text and choose Add to chat from the toolbar or the first item in the right-click menu. Your selection gives chat the text and its position in the document.

Check and save your changes.

Changes save back to the opened file when the host permits writing. Check the Saved status before closing. Keep a backup of important documents and review AI edits.

The plugin works with files you open in a supported ChatGPT or Codex host. Available file access and saving depend on the host.
