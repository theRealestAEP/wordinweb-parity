MCP server · Free · No account

Let your AI assistant edit Word documents.

Add one address to Claude, Codex, Cursor, or any app that supports MCP. The assistant then opens the WordInWeb editor and makes its edits there while you watch.

https://mcp.word-in-web.com/mcp

Claude (claude.ai and the Claude app)

  1. Open Settings → Connectors.
  2. Choose Add custom connector.
  3. Enter the name Word in Web and the address above. Leave sign-in empty.
  4. Start a new chat and ask: “Open the Word editor.”

The editor opens inside the chat. Choose a .docx file or start a blank document, then ask Claude for changes.

Claude Code

claude mcp add --transport http word-in-web https://mcp.word-in-web.com/mcp

Codex

codex mcp add word-in-web --url https://mcp.word-in-web.com/mcp

Cursor and other apps

Add this to the app’s MCP settings file:

{
  "mcpServers": {
    "word-in-web": { "url": "https://mcp.word-in-web.com/mcp" }
  }
}

In apps that cannot show the editor inside the chat, the assistant gives you a link. Open it in your browser to see the document and the edits.

Edit files on your computer instead

The @wordinweb/mcp package runs on your computer with Node.js 20 or later. It opens and saves .docx files on your disk, and no document data leaves your computer.

claude mcp add word-in-web-local -- npx -y @wordinweb/mcp

What the assistant can do

  • Read the document text, tables, comments, and tracked changes.
  • Rewrite passages and keep the existing formatting.
  • Add comments and tracked changes for you to review.
  • Export an edited .docx for you to download.

Your documents

The document opens in your browser, and the editing happens there. Each editor link has a private ID. Do not share the link, because anyone with it can join the session. See the privacy page for details on short-lived file copies.
