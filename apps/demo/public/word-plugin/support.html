Help with the Word plugin

Contact support.

Email Alex Pickett at alex@cobbery.com.

For bugs, setup questions, feedback, or privacy requests, use the same address.

Help us understand the problem.

Include whether you use ChatGPT or Codex, your device and operating system, what you tried, and the error message. A screenshot or a small example document can help. Remove private information from anything you send.

Chat disconnected?

Check the save status. Reopen the document to reconnect, then wait for Chat connected before asking for another edit.

Changes are read-only?

Saving requires write access from the host. If the editor shows Read-only, changes stay in that view. Open a writable copy to save changes.

The file changed elsewhere?

The editor asks you to choose between the file on disk and your open version. Keep a backup, then select the version you want to keep.
